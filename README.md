# 2025-prospecto

**Usage:**

- `❯ git clone https://github.com/hastebrot/2025-prospecto`
- `❯ cd sources/prospecto-api/`
- `❯ bun install`
- `❯ bun run restate-server`
- `❯ bun run test --watch restate`
- `❯ open -a safari --url "http://localhost:9070/"`
