### Payments

| Term     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **IBAN** | Length: minimum 15 character, maximum 34 characters<br><br>AA12 1234 1234 1234 1234 1234<br><br>`DEkk bbbb bbbb cccc cccc cc` (k = Check digits, b = Bank and branch identifier, c = Account number)<br><br>`FRkk bbbb bsss sscc cccc cccc cxx` (k = Check digits, b = National bank code, s = Branch code, c = Account number, x = National check digits)<br><br>`GBkk bbbb ssss sscc cccc cc` (k = Check digits, b = BIC bank code, s = Bank and branch code, c = Account number)<br><br>`ESkk bbbb ssss xxcc cccc cccc` (k = Check digits, b = National bank, s = Branch code, x = Check digits, c = Account number)<br><br>`ITkk xbbb bbss sssc cccc cccc ccc` (k = Check digits, x = Check character, b = National bank code, s = Branch code, c = Account number) |
| BIC      | Length: 8 or 11 characters<br><br>BBBB CC LL bbb (B = Bank code, C = Country code, L = Location code, b = Branch code)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| BLZ      | Length: 8 digits in Germany, 5 digits in Austria<br><br>123 123 12                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
